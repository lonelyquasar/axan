# axan docs

Longer guides that would crowd the root [README](../README.md).

- [Authoring `startup-sessions.toml`](startup-sessions-toml.md): write a startup tree by hand or with an agent, import it, and choose icons Windows can draw. Covers every key, the import rules, and glyph sets with code points.
- [Program Status Protocol (OSC 7501)](program-status-osc-7501.md): how a program reports idle, working, done, blocked or error to the sidebar, how each state looks in a row, the sidebar settings, and troubleshooting. The root README's [Session state in the sidebar](../README.md#session-state-in-the-sidebar) is the short summary.

The root README remains the reference for building, configuration and logging.
